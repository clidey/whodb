# Use WhoDB with MongoDB

Use the MongoDB workflow when you need to inspect documents whose fields can vary between records. Begin with a small sample, identify the fields relevant to the question, and check more than one document before assuming the collection has one fixed shape.

## Connect to the collection's database

Choose **MongoDB** and enter the endpoint, database, credentials, and advanced options required by the deployment. Use the matching compatible-product entry when connecting to a catalog product such as FerretDB.

For a server-configured profile, use `WHODB_MONGODB` or its numbered variant. Authentication and TLS requirements belong to the actual endpoint; do not copy them from an unrelated deployment merely because it is also MongoDB-compatible.

## Inspect documents

Open a collection's **Data** view and read several records. Look for missing fields, null values, nested structures, and differences in value type. A field present in the first document may be absent from the next one.

Use an exact identifier or a source-supported condition when investigating one record. A text search of the loaded page does not establish that a matching document is absent from the collection.

## Query with native syntax

Scratchpad uses shell-style MongoDB commands rather than SQL. Start with a query for a known collection, such as:

```javascript
db.users.find({})
```

Replace `users` with your collection. Add filtering using the syntax supported by the connected source. Check the [MongoDB manual](https://www.mongodb.com/docs/manual/) for the operators you intend to use.

## Edit and move document data

Use the document editing controls provided by the source for supported writes, then read the stored document again. Check the structure as well as the changed value.

JSON Lines export is available for supported document records. Inspect the file before passing it to another tool, especially when documents have different fields or nested values.

See [Connection options](/features/database-connectivity) and [Supported databases](/resources/supported-databases) for catalog availability and the tools shown for each source.
