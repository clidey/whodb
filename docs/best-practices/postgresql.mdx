# Use WhoDB with PostgreSQL

Use the PostgreSQL workflow when you need to browse a schema, inspect a few records, and run SQL against a PostgreSQL database. Start by choosing the correct database and schema; a valid connection can still be looking at the wrong set of objects.

## Connect to the intended database

Choose **Postgres** and enter the endpoint, port, database, credentials, and required TLS options. After connecting, select the schema in the sidebar.

For a server-configured profile, use `WHODB_POSTGRES` or its numbered variant. See [Connection options](/features/database-connectivity) for profiles, certificate paths, and container networking.

If you use a PostgreSQL-compatible product, choose its catalog entry when one is available. Compatibility does not mean every product has the same port, options, or supported operations.

## Inspect before querying

Find a table in **Tables** and open **Info** to read its columns and keys. Open **Data** for a row sample. Use Graph when you need to follow declared relationships to another table.

Qualify the object name when the schema matters. For example, the documentation's PostgreSQL demo uses `test_schema.users`; that is different from a table named `users` in another schema.

```sql
SELECT id, username, email
FROM test_schema.users
ORDER BY id
LIMIT 25;
```

Replace the demo names with your own. An explicit field list and order make a sample easier to inspect and compare later.

## Make a small change deliberately

For a one-record correction, filter by its key and use the Data view's editing controls. Save the change, then read the record again. For an application schema change, keep the definition in a migration instead of relying on a browser session as the record of the change.

## Investigate a slow query

Keep the original statement, check a smaller result, and inspect the plan when needed. Read [PostgreSQL's explain documentation](https://www.postgresql.org/docs/current/using-explain.html) before choosing options that execute the statement.

The [PostgreSQL manual](https://www.postgresql.org/docs/current/) is the reference for server-specific SQL and administration. Use WhoDB's [database catalog](/resources/supported-databases) to check the connection types exposed by CE.
