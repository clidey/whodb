# Cloud Providers

Cloud-provider management and discovery are available only through the local WhoDB CLI. The CE web server does not load provider credentials or expose provider management, discovery, or database-token operations through GraphQL.

The CLI uses the provider configuration and credential sources available to the user running it. Provider support remains disabled by default and must be explicitly enabled for local CLI use.

## CLI Commands

```bash
whodb cloud providers list
whodb cloud providers test <provider-id>
whodb cloud providers refresh --all
whodb cloud connections list
```

See [CLI and MCP](/features/cli-and-mcp) for the complete command reference.

## Provider Flags

| Variable | Purpose |
|----------|---------|
| `WHODB_ENABLE_AWS_PROVIDER=true` | Enable AWS providers for CLI discovery |
| `WHODB_ENABLE_AZURE_PROVIDER=true` | Enable Azure providers for CLI discovery |
| `WHODB_ENABLE_GCP_PROVIDER=true` | Enable GCP providers for CLI discovery |

These variables do not enable cloud-provider functionality in the CE web server.

## Web Connections

To connect through the CE web interface, enter the database endpoint and database credentials directly or use a server-configured source profile. The web interface does not request or store cloud-account credentials.
