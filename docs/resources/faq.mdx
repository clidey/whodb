# Frequently asked questions

## Do I need a WhoDB account?

CE connects with database credentials or configured profiles. A server-configured profile lets instance users connect with its stored credentials; it does not create a separate WhoDB user account. Restrict access to an instance that has privileged profiles. See [First connection](/first-login).

## Which databases can I use?

Check [Supported databases](/resources/supported-databases) for the CE catalog. Actions vary by source and build: a PostgreSQL table, MongoDB collection, and Redis key do not support the same operations.

## Why is an action missing?

First check whether the source and object support it. Some actions are intentionally absent for sources that cannot perform them. A visible action can also fail because the database account lacks permission. Check the source capability and account grants separately.

## Does Search find records anywhere in the table?

Search checks the rows currently loaded in the grid. To retrieve matching records from the database, use **Filter** and click **Run**, or write a query in Scratchpad. [Filtering and searching](/data/filtering-searching) explains the difference.

## Will Export use my Data view filters?

A whole-object export does not inherit the grid's filters. Use a query-result export for a filtered report, or select particular records and use the selected-row action. Check [Export options](/advanced/export-options) before exporting an important dataset.

## Where are my Scratchpad pages and history?

They are local to the browser. They can survive a normal reload but are not automatically available in another browser or shared with teammates. Clearing browser storage can remove them. Keep important SQL in your own files or version control.

## Can I undo a change?

Some table deletions offer a short-lived **Undo** action that attempts to reinsert the deleted rows where insertion is supported. It is not a database rollback and does not restore every related effect. See [Deleting records](/data/deleting-records). Do not assume arbitrary Scratchpad writes can be undone by WhoDB.

## Is an export a database backup?

An export gives you records or query results. A recoverable database backup can also require schema, privileges, routines, and engine-specific metadata. Use [native backup tools](/resources/integrations/backup-tools) and test restoration.

## Does Chat need a cloud model?

You can configure a reachable local Ollama or LM Studio endpoint, or a remote provider. Browsing and querying do not require Chat. See [AI setup](/ai/setup-providers).

## Can my assistant use WhoDB?

Use the [CLI MCP server](/features/cli-and-mcp) and choose its query permissions deliberately. [MCP permissions](/features/mcp-permissions) explains automatic reads and confirmed execution.

## How do I update?

Use a published image or artifact from [WhoDB releases](https://github.com/clidey/whodb/releases). Preserve the data directory and encryption key when retaining existing sessions matters. Follow [release verification](/resources/changelog) after updating.
