# Keyboard shortcuts

Use these shortcuts to move between views, inspect records, and run queries without leaving the keyboard. Press `?` in the app for help or `Mod + K` to find an available action. The [CLI/TUI](/features/cli-and-mcp) has its own keymap.

<Tip>
`Mod` means `Cmd` on macOS and `Ctrl` on Windows/Linux.
</Tip>

## Global shortcuts

| Shortcut | Action |
|----------|--------|
| `?` | Open keyboard shortcuts help |
| `Mod + K` | Open command palette |
| `Esc` | Close dialogs and overlays |
| `Mod + B` | Toggle the sidebar |

## Navigation shortcuts

The numbered navigation shortcuts are platform-specific:

- macOS: `Ctrl + 1` through `Ctrl + 4`
- Windows/Linux: `Alt + 1` through `Alt + 4`

These shortcuts move through the primary routes that are available for the current database type. On SQL databases that typically means:

1. Chat
2. Tables
3. Graph
4. Scratchpad

On NoSQL or reduced-capability databases, the numbering shifts because not every route is available.

## Table navigation

Focus the grid before using its navigation keys. Moving the focused row and loading another results page are separate actions.

| Shortcut | Action |
|----------|--------|
| `Arrow Down` | Move selection down |
| `Arrow Up` | Move selection up |
| `Home` | Jump to the first row in the current view |
| `End` | Jump to the last row in the current view |
| `Page Down` | Move down a page |
| `Page Up` | Move up a page |
| `Mod + Arrow Right` | Go to the next results page |
| `Mod + Arrow Left` | Go to the previous results page |

## Table selection

Selection applies to records in the current view. Check the selected-row count before exporting or deleting records.

| Shortcut | Action |
|----------|--------|
| `Space` | Toggle selection on the focused row |
| `Shift + Arrow Down` | Extend selection downward |
| `Shift + Arrow Up` | Extend selection upward |
| `Mod + A` | Select all rows in the current view |

## Table actions

Actions depend on the source, object, and database account. A shortcut does not add an operation that the current source does not support.

| Shortcut | Action |
|----------|--------|
| `Enter` | Edit the focused row |
| `Mod + E` | Edit the focused row |
| `Mod + Delete` | Delete the focused row |
| `Mod + Backspace` | Delete the focused row |
| `Mod + Shift + G` | Open mock data generation |
| `Mod + R` | Refresh data |
| `Mod + Shift + E` | Open export |
| `Mod + I` | Open import |

## Scratchpad editor

These editor shortcuts apply to the active query cell. Check its connection context before executing a statement.

| Shortcut | Action |
|----------|--------|
| `Mod + Enter` | Execute the current query |
| `Mod + U` | Clear the current editor |

## Notes

If a key does not trigger the expected action, check focus and open the in-app help for the active list. Your browser or operating system may also handle a key combination. Desktop menus expose accelerators for supported application actions.
