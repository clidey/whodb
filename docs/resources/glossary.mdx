# Workspace glossary

These terms describe the connection, objects, and workspace used throughout the docs. Source-specific names can differ: a SQL source has tables and rows, while a document source has collections and documents.

## Connections and data

| Term | Meaning |
| --- | --- |
| Source | The system WhoDB connects to, such as a database, document store, or cache |
| Connection | The endpoint, credentials, and options used to reach a source |
| Profile | A reusable connection definition. Server-configured CE profiles can be used by anyone who can reach that instance |
| Database | A source-specific database context, or a database file for a file-backed source |
| Schema | A namespace within a database that supports schemas |
| Storage unit / object | A browsable object, such as a table or collection |
| Field / column | A named attribute in an object's structure or returned result |
| Record / row | One unit of returned data |
| Primary key | A field or group of fields that identifies a table record |
| Foreign key | A declared reference from fields in one table to a key in another |

## Browser workspace

| Term | Meaning |
| --- | --- |
| Info | The action that expands an object's metadata and field definitions |
| Data | The action that opens an object's records |
| Filter / WHERE condition | A comparison sent to the source to retrieve matching records |
| Search | A text lookup within currently loaded grid rows |
| Graph | A view of selected objects and relationships exposed by the source |
| Scratchpad page | A named tab containing query cells |
| Cell | A query editor with its own output and history |
| Query result | The records returned by a query, which may differ from the complete contents of an object |

## Models and assistants

| Term | Meaning |
| --- | --- |
| Provider | A configured AI service or local model endpoint |
| Model | The model identifier selected for a provider |
| Chat | WhoDB's in-app conversation for working with the connected source |
| MCP | The protocol assistants use to call tools exposed by the CLI server |
| Protected read | A query accepted as a read and executed with the connector's read restrictions. See [MCP permissions](/features/mcp-permissions) |
