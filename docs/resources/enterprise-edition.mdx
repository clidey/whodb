# Enterprise Edition

If CE does not cover a source or support requirement your organization has, evaluate WhoDB's commercial offering against that specific need. Keep the working CE connection and a representative task as the basis for that conversation.

## Identify what you need to add

Start with the requirement that prevents you from completing the work. It might be a source outside the [CE catalog](/resources/supported-databases), a commercial support agreement, or a deployment requirement.

Record the source product and version, authentication method, network arrangement, and operations you need. Reading records, changing schema, and moving large datasets are different requirements; support for one should not be taken as proof of the others.

## Verify the proposed package

Review the currently offered connectors, packaging, and support terms with the WhoDB team. Test the exact source and workflow before adopting it. Package availability and terms belong in the current commercial discussion rather than a static feature promise in these docs.

Keep durable queries, fixtures, and migrations in your own repository so you can reproduce the evaluation and retain the work independently of a client.

## When the need is a shared workflow

If you want to turn an investigation into a recurring data pipeline, model business entities, or build an operational app, start with [WhoDB Platform](/guides/move-to-platform). That guide explains Transforms, Ontology, Apps, and bringing a CE connection across.

[Explore WhoDB](https://whodb.com) to find the current public product information and contact options.
